# MathExplorer

An interactive math learning site hosted on **GitHub Pages** — explore core mathematics concepts through visual explanations and (soon) interactive graphs.

🔗 **Live site:** [priyadharsan17.github.io/MathExplorer](https://priyadharsan17.github.io/MathExplorer)

---

## Categories

| Category | Description |
|---|---|
| **Algebra** | Equations, polynomials, functions, matrices |
| **Calculus** | Limits, derivatives, integrals, series |
| **Trigonometry** | Unit circle, sine/cosine, identities, waves |

## Getting Started

The site is plain HTML/CSS/JS — no build step required.

```bash
# Clone the repo
git clone https://github.com/priyadharsan17/MathExplorer.git

# Open in browser
open index.html
```

Or just visit the live GitHub Pages URL above.
