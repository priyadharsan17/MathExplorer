Continuity

A function is continuous if you can draw its graph without lifting your pencil. Formally, it requires three conditions: the function must be defined, its limit must exist, and the two must agree — at every point in its domain.

The Three Conditions

A function \(f\) is continuous at \(x = a\) if and only if all three hold:

1. \(f(a)\) is defined.   2. \(\displaystyle\lim_{x \to a} f(x)\) exists.   3. \(\displaystyle\lim_{x \to a} f(x) = f(a)\).

Violating any one of these produces a discontinuity. There are three classic types: removable (a single hole), jump (left and right limits differ), and infinite (the function grows without bound).

Types of Discontinuity

Removable
\[ \lim_{x \to a} f(x) = L \text{ but } f(a) \ne L \]
A single "hole" — the limit exists but the function value is wrong or missing. Fixable by redefining \(f(a) = L\).
Jump
\[ \lim_{x \to a^-} f(x) \ne \lim_{x \to a^+} f(x) \]
The function "jumps" to a different value. The two-sided limit does not exist.
Infinite
\[ \lim_{x \to a} f(x) = \pm\infty \]
A vertical asymptote — common in rational functions where the denominator is zero.
IVT
\[ f \text{ cont. on } [a,b],\ f(a) \ne f(b) \Rightarrow \exists\,c: f(c)=k \]
Intermediate Value Theorem — a continuous function hits every value between \(f(a)\) and \(f(b)\).

Worked Examples

Example 1 — Checking continuity
Is \(f(x) = \dfrac{x^2-1}{x-1}\) continuous at \(x = 1\)?
1
Check condition 1: \(f(1)\) is undefined (division by zero). Already fails.
2
The limit exists: factor to \((x+1)\) → \(\lim_{x\to1}(x+1) = 2\).
✓
Removable discontinuity at \(x=1\). Redefine \(f(1)=2\) to make it continuous.
Example 2 — Jump discontinuity
Analyse \(f(x) = \begin{cases} x+1 & x < 0 \\ x-1 & x \ge 0 \end{cases}\)
1
\(\lim_{x\to 0^-}f(x) = 0 + 1 = 1\)
2
\(\lim_{x\to 0^+}f(x) = 0 - 1 = -1\)
✓
Left ≠ Right → Jump discontinuity at \(x=0\). Not fixable.
Example 3 — Applying the IVT
Show that \(f(x) = x^3 - x - 1\) has a root in \([1, 2]\).
1
\(f\) is a polynomial — continuous everywhere.
2
\(f(1) = 1 - 1 - 1 = -1 < 0\) and \(f(2) = 8 - 2 - 1 = 5 > 0\).
✓
By IVT, there exists \(c \in (1,2)\) where \(f(c) = 0\).

Key Takeaways

◈

Continuity requires the function to be defined, the limit to exist, and both to agree at every point.

◈

Removable discontinuities are "fixable" — jump and infinite ones are not.

◈

Differentiability implies continuity — but continuity does not imply differentiability.

◈

The Intermediate Value Theorem only applies to continuous functions — a powerful existence tool.
