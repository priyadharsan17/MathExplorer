Limits

A limit describes the value a function approaches as the input gets closer and closer to some value — even if the function never actually reaches it. Limits are the foundation of all of calculus.

What is a Limit?

We write \(\displaystyle\lim_{x \to a} f(x) = L\) to mean: as \(x\) gets arbitrarily close to \(a\) (from either side), the output \(f(x)\) gets arbitrarily close to \(L\).

Crucially, the limit is about the approach, not the value at \(a\). The function may be undefined at \(x = a\) or may have a different value there — the limit doesn't care. This lets us handle holes, cusps, and the very foundations of derivatives and integrals.

A limit exists only when the left-hand limit and right-hand limit both exist and are equal: \(\displaystyle\lim_{x \to a^-} f(x) = \lim_{x \to a^+} f(x) = L\).

Key Definitions & Rules

Definition
\[ \lim_{x \to a} f(x) = L \]
For every \(\varepsilon > 0\) there exists \(\delta > 0\) such that \(0 < |x-a| < \delta \Rightarrow |f(x)-L| < \varepsilon\)
One-Sided Limits
\[ \lim_{x \to a^-} f(x) \quad \text{and} \quad \lim_{x \to a^+} f(x) \]
Left-hand (\(x \to a^-\)) and right-hand (\(x \to a^+\)) limits. Both must agree for the two-sided limit to exist.
Limit Laws
\[ \lim[f \pm g] = \lim f \pm \lim g \]
Also: \(\lim[f \cdot g] = \lim f \cdot \lim g\) and \(\lim[f/g] = \lim f / \lim g\) (provided \(\lim g \ne 0\))
Special Limit
\[ \lim_{x \to 0} \frac{\sin x}{x} = 1 \]
A foundational result — proves the derivative of \(\sin x\) is \(\cos x\).

Worked Examples

Example 1 — Direct substitution
Find \(\displaystyle\lim_{x \to 3}(2x + 1)\)
1
The function is continuous everywhere. Substitute \(x = 3\) directly.
2
\(2(3) + 1 = 7\)
✓
\(\displaystyle\lim_{x \to 3}(2x+1) = 7\)
Example 2 — Removable discontinuity (0/0 form)
Find \(\displaystyle\lim_{x \to 2} \frac{x^2 - 4}{x - 2}\)
1
Direct substitution gives \(0/0\) — indeterminate. Factor the numerator.
2
\(\displaystyle\frac{x^2-4}{x-2} = \frac{(x-2)(x+2)}{x-2} = x + 2\) (for \(x \ne 2\))
3
Now substitute: \(\lim_{x \to 2}(x+2) = 4\)
✓
The limit is \(4\) even though the function is undefined at \(x = 2\).
Example 3 — One-sided limits (non-existent limit)
Does \(\displaystyle\lim_{x \to 0} \frac{|x|}{x}\) exist?
1
For \(x > 0\): \(|x|/x = x/x = 1\), so \(\lim_{x\to 0^+} = 1\).
2
For \(x < 0\): \(|x|/x = -x/x = -1\), so \(\lim_{x\to 0^-} = -1\).
✓
Left ≠ Right, so the two-sided limit does not exist.

Key Takeaways

◈

A limit is about approach, not arrival — the function need not be defined at \(a\).

◈

Both one-sided limits must exist and agree for the two-sided limit to exist.

◈

Indeterminate forms like \(0/0\) require algebraic manipulation (factoring, rationalising) or L'Hôpital's rule.

◈

Every derivative and every integral is defined in terms of a limit — they are the backbone of calculus.
