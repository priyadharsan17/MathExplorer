Indefinite Integrals

An indefinite integral finds the family of antiderivatives of a function — all functions whose derivative equals \(f(x)\). The constant \(C\) represents every possible vertical shift, giving an infinite family of parallel curves.

Antiderivatives and the +C

If \(F'(x) = f(x)\), then \(F\) is an antiderivative of \(f\). Since any constant has derivative zero, \(F(x) + C\) is also an antiderivative for any constant \(C\). We write: \[\int f(x)\,dx = F(x) + C\]

The indefinite integral is the inverse operation of differentiation. To "undo" a derivative you integrate; to "undo" an integral you differentiate. This relationship is made precise by the Fundamental Theorem of Calculus.

The constant \(C\) is not just a formality — it carries real physical meaning. In motion problems, \(C\) is determined by an initial condition (e.g. starting position or velocity).

Key Integration Rules

Power Rule for ∫
\[ \int x^n\,dx = \frac{x^{n+1}}{n+1} + C \quad (n \ne -1) \]
E.g. \(\int x^3\,dx = \tfrac{x^4}{4} + C\).
Constant & Sum
\[ \int c\,f(x)\,dx = c\int f(x)\,dx, \quad \int [f \pm g]\,dx = \int f \pm \int g \]
Constants factor out; integrals split across sums.
Trig Integrals
\[ \int \cos x\,dx = \sin x + C, \quad \int \sin x\,dx = -\cos x + C \]
These are the reverse of the trig derivative rules.
Exponential
\[ \int e^x\,dx = e^x + C, \quad \int \frac{1}{x}\,dx = \ln|x| + C \]
The exponential is its own antiderivative. The \(1/x\) rule handles \(n = -1\).

Worked Examples

Example 1 — Polynomial antiderivative
Find \(\displaystyle\int (3x^2 - 4x + 1)\,dx\)
1
Integrate term by term: \(\int 3x^2\,dx = x^3\)
2
\(\int -4x\,dx = -2x^2\), \(\int 1\,dx = x\).
✓
\(x^3 - 2x^2 + x + C\)
Example 2 — Using an initial condition
Find \(F(x)\) if \(F'(x) = 2x\) and \(F(0) = 5\).
1
Integrate: \(\int 2x\,dx = x^2 + C\)
2
Apply condition: \(F(0) = 0 + C = 5 \Rightarrow C = 5\)
✓
\(F(x) = x^2 + 5\)
Example 3 — Trig antiderivative
Find \(\displaystyle\int (2\cos x - 3\sin x)\,dx\)
1
\(\int 2\cos x\,dx = 2\sin x\)
2
\(\int -3\sin x\,dx = 3\cos x\)
✓
\(2\sin x + 3\cos x + C\)

Key Takeaways

◈

An indefinite integral yields a family of functions — the \(+C\) represents every parallel antiderivative curve.

◈

Always add \(+C\) to an indefinite integral result — omitting it is incorrect.

◈

An initial condition (a known function value) pins down the exact value of \(C\).

◈

Integration is differentiation in reverse — verify any antiderivative by differentiating it.
