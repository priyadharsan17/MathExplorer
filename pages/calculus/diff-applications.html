Applications of Derivatives

Derivatives tell you where a function is increasing, decreasing, and curving. That information locates maxima, minima, and inflection points — powering optimisation in science, engineering, and economics.

Using f' and f'' to Analyse Curves

The first derivative test: if \(f'(c) = 0\) (a critical point), check the sign of \(f'\) around \(c\). If it changes from \(+\) to \(-\), there's a local maximum; from \(-\) to \(+\), a local minimum.

The second derivative test: at a critical point, if \(f''(c) > 0\) the curve is concave up (local min); if \(f''(c) < 0\) concave down (local max); if \(f''(c) = 0\) the test is inconclusive.

An inflection point is where concavity changes — i.e. \(f''\) changes sign.

Key Results

Critical Points
\[ f'(c) = 0 \text{ or } f'(c) \text{ undefined} \]
Every local extremum occurs at a critical point (but not every critical point is an extremum).
Increasing / Decreasing
\[ f' > 0 \Rightarrow \text{increasing}, \quad f' < 0 \Rightarrow \text{decreasing} \]
Sign of the derivative determines direction of the function.
Concavity
\[ f'' > 0 \Rightarrow \text{concave up}, \quad f'' < 0 \Rightarrow \text{concave down} \]
Concave up looks like a cup; concave down like a cap.
Mean Value Theorem
\[ \exists\, c \in (a,b) : f'(c) = \frac{f(b)-f(a)}{b-a} \]
There is always a point where the instantaneous rate equals the average rate over \([a,b]\).

Worked Examples

Example 1 — Finding critical points and extrema
Analyse \(f(x) = x^3 - 3x\)
1
\(f'(x) = 3x^2 - 3 = 3(x^2 - 1)\). Set to zero: \(x = \pm 1\).
2
Sign test: \(f' > 0\) on \((-\infty,-1)\), \(f' < 0\) on \((-1,1)\), \(f' > 0\) on \((1,\infty)\).
3
Local max at \(x = -1\): \(f(-1) = 2\). Local min at \(x = 1\): \(f(1) = -2\).
✓
\(f''(x) = 6x\). \(f''(-1) = -6 < 0\) (max) ✓. \(f''(1) = 6 > 0\) (min) ✓.
Example 2 — Inflection point
Find the inflection point of \(f(x) = x^3\)
1
\(f''(x) = 6x\). Set to zero: \(x = 0\).
2
\(f'' < 0\) for \(x < 0\) (concave down) and \(f'' > 0\) for \(x > 0\) (concave up).
✓
Inflection point at \((0, 0)\) — concavity changes here.

Key Takeaways

◈

Set \(f'(x) = 0\) to find critical points — then use sign changes or \(f''\) to classify them.

◈

\(f'' > 0\) means concave up (holds water); \(f'' < 0\) means concave down (spills water).

◈

Inflection points are where concavity switches — \(f''\) changes sign there.

◈

Optimisation problems reduce to: find critical points, evaluate at endpoints, pick the winner.
