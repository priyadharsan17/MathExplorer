Inverse Trig Functions

Inverse trig functions answer "which angle has this sine/cosine/tangent?" They require restricted domains to be well-defined, and their graphs are reflections of the original functions across \(y = x\).

Restricted Domains and Inverses

Because \(\sin x\) is not one-to-one over all reals, we restrict its domain to \([-\pi/2, \pi/2]\) before defining \(\arcsin\). Similarly \(\arccos\) uses \([0, \pi]\) and \(\arctan\) uses \((-\pi/2, \pi/2)\).

The graph of \(y = \arcsin x\) is the reflection of the restricted \(y = \sin x\) graph across the line \(y = x\) — input and output swap roles.

Key Formulas

arcsin
\[ y = \arcsin x \iff \sin y = x, \quad x\in[-1,1],\; y\in\left[-\tfrac{\pi}{2},\tfrac{\pi}{2}\right] \]
arccos
\[ y = \arccos x \iff \cos y = x, \quad x\in[-1,1],\; y\in[0,\pi] \]
arctan
\[ y = \arctan x \iff \tan y = x, \quad x\in\mathbb{R},\; y\in\left(-\tfrac{\pi}{2},\tfrac{\pi}{2}\right) \]
Derivatives
\[ \frac{d}{dx}\arcsin x = \frac{1}{\sqrt{1-x^2}}, \quad \frac{d}{dx}\arctan x = \frac{1}{1+x^2} \]

Worked Examples

Example 1 — Evaluating arcsin
Find \(\arcsin(1/2)\)
1
We need angle \(y\) in \([-\pi/2,\pi/2]\) with \(\sin y = 1/2\).
✓
\(\arcsin(1/2) = \pi/6 = 30°\)
Example 2 — Evaluating arctan
Find \(\arctan(-1)\)
1
We need \(y\) in \((-\pi/2,\pi/2)\) with \(\tan y = -1\).
✓
\(\arctan(-1) = -\pi/4 = -45°\)

Key Takeaways

◈

Inverse trig functions need restricted domains to be well-defined (pass the horizontal line test).

◈

\(\arcsin\) and \(\arccos\) are only defined for inputs in \([-1,1]\); \(\arctan\) accepts all reals.

◈

The graph of each inverse is the mirror image of the restricted original across \(y = x\).
