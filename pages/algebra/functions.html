Functions & Graphs

A function maps every input to exactly one output. Understanding the common function families — and how transformations shift, stretch, and reflect their graphs — is central to all of mathematics.

What is a Function?

A function \(f\) is a rule that assigns to each input \(x\) in its domain exactly one output \(f(x)\) in its range. The key test: for any \(x\)-value, there is only one \(y\)-value (the vertical line test — a vertical line should cross the graph at most once).

Transformations let you build complex functions from simple ones. Given a base function \(f(x)\), the general transformed form \(g(x) = a \cdot f(x - h) + k\) applies: vertical stretch/flip (\(a\)), horizontal shift (\(h\)), and vertical shift (\(k\)).

Transformations

General Form
\[ g(x) = a \cdot f(x - h) + k \]
\(a\): vertical stretch/compress/flip  |  \(h\): horizontal shift  |  \(k\): vertical shift
Reflections
\[ -f(x) \text{ reflects over x-axis}, \quad f(-x) \text{ reflects over y-axis} \]
Composition
\[ (f \circ g)(x) = f(g(x)) \]
Apply g first, then f — order matters!

Worked Examples

Example 1 — Evaluating and finding domain
For \(f(x) = \sqrt{x - 3}\), find \(f(7)\) and state the domain.
1
Evaluate: f(7) = √(7 − 3) = √4 = 2
2
Domain: need x − 3 ≥ 0, so x ≥ 3 → Domain: \([3, \infty)\)
Example 2 — Describing a transformation
Describe how \(g(x) = -2(x - 1)^2 + 3\) relates to \(f(x) = x^2\)
1
a = −2: vertical stretch by 2, reflected over x-axis (opens downward)
2
h = 1: shifted right 1 unit
3
k = 3: shifted up 3 units. Vertex at \((1, 3)\)

Key Takeaways

◈

A function passes the vertical line test: every \(x\)-value maps to exactly one \(y\)-value.

◈

The transformation \(g(x) = a \cdot f(x - h) + k\) encodes stretch, flip, and shift — in that order.

◈

Domain restrictions arise from square roots (need argument ≥ 0) and reciprocals (denominator ≠ 0).

◈

Horizontal shifts move opposite to the sign: \(f(x - 3)\) shifts right 3 units.
