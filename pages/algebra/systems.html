Systems of Equations

A system of equations asks: where do two (or more) lines meet? The solution is the point \((x, y)\) that satisfies all equations simultaneously.

What is a System of Equations?

A system of linear equations is a set of two or more equations with the same variables. Geometrically, each equation is a line; the solution is where those lines intersect.

Three outcomes are possible:

  • One solution — lines intersect at exactly one point (different slopes)
  • No solution — lines are parallel (same slope, different intercepts)
  • Infinitely many — lines are identical (same slope and intercept)

Solving Methods

Graphing

Plot both lines. The intersection point is the solution. Best for visual understanding; imprecise for irrational solutions.

Substitution

Solve one equation for one variable, substitute into the other. Best when one variable is already isolated.

Elimination

Add or subtract equations to cancel a variable. Best when coefficients are easy to match.

Cramer's Rule

Uses determinants: \(x = D_x / D\), \(y = D_y / D\). Efficient for 2×2 systems.

Key Formulas

General 2×2 System
\[ \begin{cases} a_1 x + b_1 y = c_1 \\ a_2 x + b_2 y = c_2 \end{cases} \]
Cramer's Rule
\[ x = \frac{c_1 b_2 - c_2 b_1}{a_1 b_2 - a_2 b_1}, \quad y = \frac{a_1 c_2 - a_2 c_1}{a_1 b_2 - a_2 b_1} \]
Condition for Unique Solution
\[ D = a_1 b_2 - a_2 b_1 \neq 0 \]

Worked Examples

Example 1 — Substitution
Solve: \(\begin{cases} y = 2x + 1 \\ y = -x + 4 \end{cases}\)
1
Set equal: 2x + 1 = −x + 4
2
Solve: 3x = 3 → x = 1
3
Back-substitute: y = 2(1) + 1 = 3
✓
Solution: (1, 3)
Example 2 — Elimination
Solve: \(\begin{cases} 2x + 3y = 12 \\ 4x - 3y = 6 \end{cases}\)
1
Add the equations: 6x = 18 → x = 3
2
Substitute back: 2(3) + 3y = 12 → 3y = 6 → y = 2
✓
Solution: (3, 2)

Solving by Hand — Methods Compared

1. Rearrange one equation to isolate a variable: y = mx + b
2. Substitute the expression into the second equation (now one variable).
3. Solve the resulting single-variable equation.
4. Back-substitute to find the second variable.
5. Write the answer as an ordered pair (x, y) and verify in both equations.
1. Align the equations so matching variables are in columns.
2. Multiply one (or both) equations so a variable has equal and opposite coefficients.
3. Add the equations — that variable cancels.
4. Solve the remaining equation.
5. Substitute back to find the eliminated variable.
Given \(a_1 x + b_1 y = c_1\) and \(a_2 x + b_2 y = c_2\):
1. Compute determinant: \(D = a_1 b_2 - a_2 b_1\).
2. If \(D = 0\): no unique solution (parallel or identical lines).
3. \(D_x = c_1 b_2 - c_2 b_1\) → \(x = D_x / D\)
4. \(D_y = a_1 c_2 - a_2 c_1\) → \(y = D_y / D\)

Key Takeaways

◈

Two lines with different slopes always intersect at exactly one point.

◈

Equal slopes but different intercepts → parallel lines → no solution.

◈

Equal slopes and equal intercepts → identical lines → infinitely many solutions.

◈

The determinant \(D = a_1 b_2 - a_2 b_1\) is the algebraic test: \(D \neq 0\) guarantees a unique solution.
