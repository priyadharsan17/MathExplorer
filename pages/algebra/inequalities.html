Inequalities

An inequality compares two expressions and describes a range of solutions rather than a single value. Understanding shaded regions on a number line and graph is central to optimisation and constraints.

What is an Inequality?

An inequality uses \(<\), \(>\), \(\leq\), or \(\geq\) to relate two expressions. The solution is the set of all values that make the inequality true.

Key rule: When you multiply or divide both sides by a negative number, you must flip the inequality symbol. For example, \(-2x < 6\) becomes \(x > -3\).

On a number line, strict inequalities (\(<\), \(>\)) use an open circle; non-strict (\(\leq\), \(\geq\)) use a filled circle.

Rules for Inequalities

Addition / Subtraction
\[ a < b \implies a + c < b + c \]
Direction preserved for all c.
Multiply / Divide (positive)
\[ a < b,\ c > 0 \implies ac < bc \]
Direction preserved.
Multiply / Divide (negative)
\[ a < b,\ c < 0 \implies ac > bc \]
Direction reverses!
Interval Notation
\[ x \geq 3 \;\leftrightarrow\; x \in [3, +\infty) \]
[ ] = closed (included), ( ) = open (excluded).

Worked Examples

Example 1 — Linear Inequality
Solve: \(3x - 4 > 8\)
1
Add 4: 3x > 12
2
Divide by 3 (positive, no flip): x > 4
✓
Solution: \(x \in (4, +\infty)\). Open circle at 4, shade right.
Example 2 — Flip the symbol
Solve: \(-5x + 2 \leq 17\)
1
Subtract 2: −5x ≤ 15
2
Divide by −5 (negative → flip): x ≥ −3
✓
Solution: \(x \in [-3, +\infty)\). Closed circle at −3, shade right.
Example 3 — Quadratic Inequality
Solve: \(x^2 - x - 6 < 0\)
1
Factor: (x − 3)(x + 2) = 0 → roots at x = −2 and x = 3
2
Parabola opens upward. It is negative between the roots.
✓
Solution: \(x \in (-2, 3)\)

Key Takeaways

◈

Multiplying or dividing by a negative number reverses the inequality sign.

◈

Open circle = strict (<, >). Closed circle = non-strict (≤, ≥).

◈

For quadratic inequalities, find the roots first, then test which interval(s) satisfy the inequality.

◈

In 2D, the boundary line is solid for ≤ / ≥ and dashed for < / >; shade the side that satisfies the inequality.
