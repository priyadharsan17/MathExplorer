Factoring

Factoring reverses multiplication — it breaks an expression into a product of simpler pieces. Mastering factoring unlocks faster equation solving and reveals the roots of polynomials directly.

What is Factoring?

To factor an expression means to rewrite it as a product. For example, \(x^2 - 5x + 6 = (x - 2)(x - 3)\). The values \(x = 2\) and \(x = 3\) are immediately visible as the roots.

The key insight: a quadratic \(ax^2 + bx + c\) can be factored over the reals only when its discriminant \(\Delta = b^2 - 4ac \geq 0\). When \(\Delta < 0\), the parabola never touches the x-axis — no real factors exist.

Factoring Strategies

Step 1 — Always

Greatest Common Factor (GCF)

Factor out the largest factor shared by all terms. \(6x^2 + 9x = 3x(2x + 3)\)

a = 1

Simple Trinomial

Find p, q: \(p \cdot q = c\) and \(p + q = b\). Then \(x^2 + bx + c = (x+p)(x+q)\).

a ≠ 1

AC Method

Find p, q: \(p \cdot q = ac\) and \(p + q = b\). Rewrite \(bx = px + qx\), then factor by grouping.

Special

Difference of Squares

\(a^2 - b^2 = (a+b)(a-b)\). Example: \(x^2 - 9 = (x+3)(x-3)\).

Special

Perfect Square Trinomial

\(a^2 \pm 2ab + b^2 = (a \pm b)^2\). Example: \(x^2 + 6x + 9 = (x+3)^2\).

Key Formulas

Simple (a = 1)
\[ x^2 + bx + c = (x + p)(x + q) \quad \text{where } p+q=b,\ pq=c \]
Diff. of Squares
\[ a^2 - b^2 = (a + b)(a - b) \]
Perfect Square
\[ a^2 \pm 2ab + b^2 = (a \pm b)^2 \]

Worked Examples

Example 1 — Simple trinomial (a = 1)
Factor: \(x^2 - 5x + 6\)
1
Need p, q where p × q = 6 and p + q = −5
2
Try pairs of 6: (1,6), (2,3), (−2,−3)… Found: p = −2, q = −3 since (−2)(−3) = 6 and (−2)+(−3) = −5 ✓
✓
Factored: (x − 2)(x − 3)
Example 2 — AC Method (a ≠ 1)
Factor: \(2x^2 + 5x + 3\)
1
Compute a × c = 2 × 3 = 6. Find p, q: p × q = 6, p + q = 5 → p = 2, q = 3
2
Rewrite: 2x² + 2x + 3x + 3
3
Group: (2x² + 2x) + (3x + 3)
4
Factor each group: 2x(x + 1) + 3(x + 1)
✓
Collect: (x + 1)(2x + 3)

Key Takeaways

◈

Always check for a GCF first — it simplifies every method that follows.

◈

The discriminant \(\Delta = b^2 - 4ac\) tells you whether integer factoring is possible before you start searching.

◈

The AC method works for any \(a\) — finding the factor pair is the hardest step, everything else follows mechanically.

◈

Factored form immediately reveals the roots: if \((x - r_1)(x - r_2) = 0\) then \(x = r_1\) or \(x = r_2\).
